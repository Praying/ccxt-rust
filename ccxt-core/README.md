# ccxt-core

Core types, traits, and error handling for the [ccxt-rust](https://github.com/Praying/ccxt-rust) cryptocurrency
exchange trading library: the unified `Exchange` and `WsExchange` traits, standard market/order/account types,
and the shared error model.
